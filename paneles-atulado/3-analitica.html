Cómo se construye esta sección

La tabla perfil_estadistico guarda resultados agregados junto a variables de contexto (puesto, sexo, rango de edad, escolaridad, antigüedad, tipo de jornada, lugar de origen, interacción) sin ninguna llave que permita regresar al usuario. Sirve para mejorar el producto y para la investigación; no puede usarse para identificar a nadie ni para alimentar el panel institucional.
